# 验证与贡献

运行 `npm test` 构建当前源码并执行 Host 行为测试，`npm run check:cloud` 检查 Worker 类型，
`npm run cloud:bundle` 只生成本地部署产物。开发时在运行服务之外使用独立构建目录，避免覆盖
其已加载文件。启动测试可通过 `WISHOS_TEST_ENTRY` 指定同版本 CLI。

测试覆盖协议版本、配对隔离、会话恢复与 steer、音频压缩／识别接入、公开进度、资源配额、
不可变应用更新、原生完成回执、取消／重连和未知副作用。固定输入中的地址、会话和密钥均为虚构。

Host fixtures 验证协议行为；目标构建验证编译与空间；真实 Harness 验证账号入口；设备验收
再确认输入、实际显示完成、音频 drain 和资源清理。真实语音、实体手势和光学／听感分别记录。

提交缺陷时提供软件版本、相关能力声明、脱敏的阶段与错误码以及可复现步骤。保留请求身份用于
本机协调，但分享日志前用一致的虚构标识替换设备、会话、地址与个人路径。不要提交运行配置、
密钥存储、数据库、录音、用户资源或完整私有交接记录。

发布构建使用固定依赖和显式文件清单，归档后核对清单、摘要与许可。旧的预览资产不作为新源码
的验证证据；每个发布批次保留自己的来源和测试范围。
